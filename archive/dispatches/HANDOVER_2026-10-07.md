### D. Publish scope — DECIDED 2026-10-07: publish all of it, sequenced no-regrets

Pete's call is that everything goes out — `period=annual`, the intld / ha / prod_t / head_n tiers,
the model axis (`historic`, `ENSEMBLE`, per-GCM) and `value_sd` — **sequenced so that an error at any
point leaves no work that has to be undone.** What that requires:

- **Design the full key scheme up front, publish into it incrementally.** The scheme must carry five
  variables × two periods × the model axis before the first new key is written. `model=ENSEMBLEmean`
  is hardcoded into `S3_BASE` today, so the model axis is the part that forces the rewrite;
  `period=%s` already interpolates the timeframe, so `period=annual` costs nothing but scope.
  Changing the layout after keys exist means stale keys on a bucket where `s3fs` deletes are
  permanent.
- **Order within the publish, cheapest-to-verify and most-proven first.** Each step is independently
  gated, so a failure stops one key and not the sequence:
  1. **usd tiers, `period=jagermeyr`** — the shape the publisher already proves. Validates the new
     bake end-to-end against a known-good path before any new key exists.
  2. **intld, then ha** — new keys, twins already in the 0.4.4 reference.
  3. **prod_t, then head_n** — the new physical tiers.
  4. **`period=annual` across all five** — a proven path at a different timeframe.
  5. **model axis + `value_sd`** — last, because it is the only step that widens the read contract.
     Confirm it with Brayden before publishing, not after.
- **`value_sd` has a prerequisite:** it needs the merged `ENSEMBLE` published rather than
  `ENSEMBLEmean`, so it rides with step 5 and not earlier.

## Conventions that carry forward (from this cycle)

- **Judge a product against the input it was built from, on the same grid.** A gate's reference must
  be independent of the table it judges.
- **Allocate and price on the native 0.05° grid; aggregate afterwards.** A coarse border cell carries
  the neighbour's production.
- **Run the basis guard before the fills.** A price rejected for its own country must not feed its
  neighbours.
- **Flag the denominator-vs-product gap before publishing a denominator ahead of its product.**
- **A provenance column is a claim, not a measurement.** `pop_method` said `county-level` for eight
  days while the numbers were `county-growth`; the logs printed the truth and the parquet held the
  lie. Settle "how was this made" by re-deriving under each candidate and comparing values, not by
  reading the label. Same for metadata records — #33's source claim did not match the code either.
- **`s3fs` deletes are permanent** (AGENTS.md §2). Back up first, or use `paws` `delete_object`
  without a VersionId.
- **Evidence before pins.** Every hand-set price is in `metadata/price_pins.csv` with sources. Every
  accepted cross-basis residual is in `metadata/cross_basis_expected_residuals.csv` with a reason.
- **Stop at every gate; state expectations as invariants; background anything long.** Check
  `origin/develop` before re-sending a prompt; cglabs sessions can be stale.
- **The repository is public.** No internal addresses, hostnames or credentials (see section 0).

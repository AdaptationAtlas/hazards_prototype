## 2. The publish gates, as they now stand

`scripts/r3_publish_tiers.R` + `R/checks/r3_tier_drift_vs_live.R`. Each rule below was learned from a
stop in the #13 thread (`archive/dispatches/DISPATCH_cglabs_issue13_rebake.md`):

- **G6b** (product vs its own exposure input) is the gate for any **first publish**; G6 (vs live) can't
  run without a live object. Both read the exposure on the **admin2 basis**, never the reference's
  independently-zoned admin0 rows (#18).
- **Per-tier materiality floor** (`VAR_SPECS$g6b_min`): 1e3 for currency, 1e4 of their unit for ha/t/head.
- **Named residuals** in `metadata/g6b_expected_residuals.csv` (one row, with reason) — never widen
  `tol_pair` to excuse a pair.
- **Declared unmodelled crops** (`G6B_NO_PRODUCT_CROPS`: nine composites + TLU) reported, not gated;
  an undeclared missing crop still fails.
- **Declared livestock move** (`--livestock-moved`, #47): judges G6's livestock control net of
  `--drift-exposure` instead of raw ~1 vs live. Needs `--drift-exposure`; still fails a livestock pair
  off its new input. Only for a publish that deliberately reprices or recounts livestock.
- **Declared `hazard_vars` change** (`--hv-retired` / `--hv-added`) for a publish that deliberately
  changes the set against a live object; parity checks the arithmetic closes.
- `usd_total_vs_reference.R`: admin2 basis, **max** across `hazard_vars`, spread reported.
- Verification: on this prefix family uploads are single-part, so **ETag == MD5** (keep checking for a
  multipart `-n` suffix rather than assuming).

## Conventions that carry forward

From this cycle, on top of `AGENTS.md`:

- **A declaration is not an output.** A fixture that pins a table or a label can pass while the code
  produces nothing; test the code path, and model every transformation that runs before it.
- **A gate's tolerance has a unit.** Materiality floors and bounds must be stated in the tier's unit.
- **Gate against the basis the product is built from** (admin2), and against an independent reference
  as a second, separate check (B6).
- **Instructions are gates too.** "Stop if X appears at all" is only safe if a correct run can
  satisfy it — two stops this cycle were the instruction's fault, not the run's.
- **Measure, stop, name the cause, never pass a forbidden flag.** Every one of the six macbook defects
  this cycle was caught that way, by the node, before anything reached S3.

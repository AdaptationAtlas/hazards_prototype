## 2. Publish gates and run rules

All in `scripts/r3_publish_tiers.R` and `R/checks/r3_tier_drift_vs_live.R`.

**Gates**
- **G6b** (product vs its own exposure input, admin2 basis) is the gate for a first publish. **G6**
  (vs live) runs when a live object exists.
- **Materiality floors** are set per tier (`VAR_SPECS$g6b_min`).
- **Named residuals** go in a CSV with a reason. Never widen `tol_pair` to excuse a pair.
- **Declared unmodelled crops** (`G6B_NO_PRODUCT_CROPS`) are reported, not gated.
- **Declarations for deliberate changes** (each one still fails a change it doesn't explain):
  - **`--livestock-moved`** (new, #47): the livestock control is judged net of `--drift-exposure`.
    It requires `--drift-exposure` and still fails a livestock pair that is off its new input.
  - **`--hv-retired` / `--hv-added`**: for a deliberate change to the `hazard_vars` set.
- **Exposure-table rebuilds (new, #47):**
  - Park copies first, then run `R/checks/gate_047_reference_diff.R`.
  - Pattern: every non-target row must be value-identical; target rows must move by the measured
    factor.
  - Reuse it as the template for #54 and #52.
- **Verification:** single-part uploads, so ETag == MD5. Keep checking for a multipart `-n` suffix.
  For a value claim, also read the totals back from S3 independently.

**Fixtures:** ten `R/checks/fixture_*.R`, all must pass before any node run. `fixture_livestock_price.R`
also runs the real text of 0.4.1 §4.1.

**R/3 run rules** (OOM'd twice in §4.1's integrity check, #13 B2 and #47 E):
- Set **`R3_CHECK_WORKERS=4`**. The check only reads files, so outputs don't change.
- Watch by **PID file** (`kill -0 $(cat …pid)`), **never `pgrep -f`**: it matches its own watcher.
  In #47 a run sat dead for 17.5 h while reported as running.
- A new `errors/<tf>_read-errors.csv` is a **stop**. The check deletes corrupt tifs, so a re-run
  would otherwise build a short ensemble.
- **Resume, don't restart:** `R3_TIMEFRAMES=<tf>` with `FORCE_OVERWRITE` unset. Skip-if-exists
  does the rest.
- **Limit R/3 to one variable:** park that variable's outputs by **moving** them.
- **Never set** `FORCE_OVERWRITE`, `R3_ALLOW_41_FAILURES` or `SKIP_R3_4_1`.

## Conventions that carry forward

On top of `AGENTS.md`:

- **A declaration is not an output.** Fixtures run the real code path on upstream-shaped data.
  `fixture_livestock_price.R` evaluates 0.4.1's own §4.1 text.
- **A gate's tolerance has a unit.** State floors and bounds in the tier's unit.
- **Gate against the input the product was built from, and add an independent check.** In #47 the
  chain was:
  - the probe's measured C;
  - the rebuilt CSVs, row for row;
  - the rebuilt tables against parked copies;
  - an S3 read-back (node and macbook separately);
  - G6b.
- **Measure before fixing.** #47 started as a code reading. Its probe's GATE 0 required the probe to
  reproduce the live values exactly before measuring anything. Do the same for #14 and #54.
- **Instructions are gates too.** "Stop if X" must be satisfiable by a correct run.
- **Read a claim against the code before "fixing" it.** One #49 item (THI_mean on mean temperature)
  was the wrong way round. The code used Tmax and the CSV was right.
- **Never improvise at a stop.** The node stopped five times in #47 (a probe slice gap, a dead R/3
  run, and others). Each one was named, fixed on the macbook and resumed, with nothing reaching S3
  unverified.

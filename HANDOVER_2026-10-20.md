## Conventions that carry forward

From this cycle, on top of `AGENTS.md`:

- **A declaration is not an output.** A fixture that pins a table or a label can pass while the code
  produces nothing; test the code path, and model every transformation that runs before it.
- **A gate's tolerance has a unit.** Materiality floors and bounds must be stated in the tier's unit.
- **Gate against the basis the product is built from** (admin2), and against an independent reference
  as a second, separate check (B6).
- **Instructions are gates too.** "Stop if X appears at all" is only safe if a correct run can
  satisfy it — two stops this cycle were the instruction's fault, not the run's.
- **Measure, stop, name the cause, never pass a forbidden flag.** Every one of the six macbook defects
  this cycle was caught that way, by the node, before anything reached S3.

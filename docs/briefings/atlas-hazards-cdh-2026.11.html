1. Proposal: freeze "Atlas hazards 2026.11" and ingest that

We freeze the hazard products as they are on S3 today as one version, and the CDH records describe that version:

  • Version label 2026.11. This uses the core field version, which the v0.3.0 core schema already has. Its examples are v1.0 and 2.0-release-2, so use v1.0 if you prefer a semantic label; it's your call. Later republishes become 2026.12, …, linked by previous_version.
  • Pinned bytes (this supersedes the partial pin table in HANDOVER_2026-10-12_… §7, whose six vop_nominal-usd21 rows were re-pinned to the 2026-10-23 versions today). s3://digital-atlas is versioned. metadata/cdh/pins/atlas-hazards-2026.11_s3-versions.csv records key, size, ETag and S3 versionId for all 107 objects in this version. Any object can be fetched exactly as frozen, even after a later republish: GET https://digital-atlas.s3.amazonaws.com/<key>?versionId=<id>. Noncurrent versions are kept for at least 270 days.
  • Nothing in this version is mid-change. Pending work (section 4) publishes as a later version, never into this one.

Caveats a catalogue user needs (each is in the record notes or needs adding)

  • Currency. vop_nominal-usd21 is nominal 2021 USD. vop_intld15-21 is constant 2015 international dollars. The two must not be compared or mixed.
  • Hazard × exposure has NaN rows. About 28 % of admin2 units are NaN on some rows (no exposure or no hazard coverage). Sum with NaN-safe aggregation. Values are rounded to integers per pixel before the zonal sums.
  • Soil-layer gap (issue #56, found 2026-11-02). The NDWS/NDWL0-based hazard sets lose exposure on coastal and lakeshore cells where the shared soil rasters are NA. For example, Kenya maize is 0.9756 and cassava 0.9485 of exposure, while the soil-free PTOT set is complete. This is a property of this version; the fix comes later.
  • Livestock heat thresholds (THI) are near-saturated at the moderate tier in the humid tropics. This is known (#24/#25 thread) and does not affect values, but it does affect interpretation.
  • Baseline: NEX-GDDP historical 1995-2014; the 1981-2014 baseline exists for the time series only.

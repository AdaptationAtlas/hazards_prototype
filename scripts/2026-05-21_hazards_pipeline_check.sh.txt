# ======================================================================
# STAGE A — CR-068 categorisation Stage 1 probe (diagnostic, no edits)
# ======================================================================
# Probes hazard_timeseries_class/ (Section A) + hazard_timeseries_int/
# (Section E, Stage 1-bis added when CGlabs revealed _class/ wasn't
# always populated locally). Writes JSON to:
#   metadata/checks/68_categorisation_stage1.json

# Look for:
#   - Section A "Saturated (mean > 0.7)" — Candidate 1 of dispatch
#     (NDWS / NTx35 / PTOT raster ~1.0 in historic only).
#   - Section A "Near-zero (mean < 0.005)" — Candidate 2 (heat / wet
#     classifier returned all zeros historic).
#   - Section E "Historic-vs-future combo ratio" rows where
#     ratio > 1.5 — confirms the parquet asymmetry exists at the
#     _int/ stage already.
#   - Section D SSP370 row counts — verifies the missing-periods
#     side finding (zero rows in 2041-2060 / 2061-2080 / 2081-2100).
LOG_FILE="$LOG_DIR/cr068_probe_${STAMP}.log"
echo "CR-068 Stage 1 probe -> $LOG_FILE"

# STOP after probe finishes. Paste the SUMMARY + Section A/E tables
# back to Claude for Stage 2 diagnosis before any pipeline edits.

# ======================================================================
# STAGE C — Rebake exposure pipeline (issue #9 fix + Round 2 perf)
# ======================================================================
# Three scripts in order. All intermediate writes are preserved, so the
# pipeline is restartable from any stage if one of them fails.
